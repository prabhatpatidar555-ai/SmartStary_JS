# SmartStary_JS-Hotel-Booking-System
🏨 SmartStay – Hotel Booking and Price Comparison System

📌 About the Project

SmartStay is a web-based hotel booking and price comparison system developed using HTML, CSS, and JavaScript. It helps users search for hotels in different cities, compare hotel prices, check facilities, and view ratings before choosing a hotel.

✨ Features

- 🔍 Search hotels by city.
- 💰 Compare hotel prices.
- ⭐ View hotel ratings and facilities.
- 📅 Select check-in and check-out dates.
- 🔃 Sort hotels by price (low to high or high to low).
- 🏨 View hotel details through hotel cards.
- ✅ Demo booking confirmation page.
- 📱 Simple and user-friendly interface.

🛠️ Technologies Used

- HTML5 – Webpage structure
- CSS3 – Styling and layout
- JavaScript – Search, sorting, price calculation, and booking demo

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser or use the Live Server extension.
4. Search for a city and select your check-in and check-out dates.
5. Compare the available hotels and click Book Now to test the demo booking.

🎯 Project Objective

The main objective of SmartStay is to provide a simple platform where users can explore hotels, compare prices, and choose a suitable option according to their preferences.

⚠️ Disclaimer

This is a college demonstration project. Hotel details and prices are sample data. It does not make real hotel reservations or process payments.
